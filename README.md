# 職災地雷區 ⏰💥

同事聚會小酌時，大家圍著**一台手機**輪流點的派對小遊戲。

👉 **線上玩：** https://tim890922.github.io/workplace-minefield/

## 玩法

1. 手機平放在桌上，畫面中央是一排一模一樣的「打卡鐘」。
2. 用標題下方的 − / + 設定打卡鐘數量（3～20 個，預設 8 個，會記在瀏覽器裡）。
3. 每一輪系統會隨機把其中 1 個設成地雷（主管的陷阱）。
4. 大家輪流點一個：
   - ☕ **安全下班**：按鈕變綠、發出「叮」一聲，換下一位。
   - 🤬 **主管叫你進辦公室！乾杯！**：按鈕變紅、警報「嗶嗶嗶」、手機震動，點到的人罰酒。
5. 按「再提一盤辭職信（重新開始）」重新洗牌再來一輪。

數量越多，按鈕會自動排成 3 欄或 4 欄並縮小；回合進行中數量會鎖住，避免誤觸洗掉進度。

狀態列會顯示下一位的中獎機率，越到後面越刺激。

## 技術

- 單一 `index.html`，沒有建置流程，直接用 GitHub Pages 發佈。
- 樣式：Tailwind CSS v3（Play CDN）；圖示：Lucide（CDN，載入失敗會自動改用 emoji）。
- 音效：Web Audio API 即時合成，沒有任何音檔。
- 震動：`navigator.vibrate`（Android Chrome 支援；iOS Safari 不支援，會自動略過）。
- 螢幕常亮：支援 Screen Wake Lock 的瀏覽器在遊戲進行中不會自動熄螢幕。

## 本機執行

直接用瀏覽器打開 `index.html` 即可。
